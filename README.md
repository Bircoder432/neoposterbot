
# PosterBot Constructor

Мультиарендный конструктор анонимных Telegram-ботов для сбора предложений в каналы. Один мастер-бот позволяет любому пользователю привязать своего бота-предложку, настроить канал и управлять модераторами. Подписчики пишут в бота анонимно, а модераторы клиента одобряют или отклоняют контент через инлайн-кнопки.

Тарифы Free / Pro (100 ⭐ за 30 дней через Telegram Stars) — Pro снимает лимит на модераторов и убирает вотермарку.

## Стек

Rust 1.94 + teloxide + PostgreSQL 16 + Docker.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `MASTER_BOT_TOKEN` | Токен мастер-бота от @BotFather |
| `OWNER_ID` | Telegram ID владельца сервиса |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `WATERMARK_USERNAME` | Юзернейм для вотермарки (Free) |
| `INSTRUCTION_URL` | Ссылка на инструкцию в меню |

Шаблон — `.env.example`.

## Деплой

### Из исходников

```bash
cp .env.example .env   # заполнить
docker compose up -d --build
```

Поднимутся PostgreSQL (том `pgdata`) и приложение. Миграции применяются автоматически.

### Готовый образ из ghcr.io


```yaml
# compose.yml (фрагмент)
constructor_bot:
  image: ghcr.io/bircoder432/neoposterbot:latest
  restart: unless-stopped
  env_file: .env
  depends_on: [db]
```

```bash
docker compose pull
docker compose up -d
```


## Особенности хранения данных

- **Предложения** живут только в оперативной памяти и не попадают в БД — после публикации/отказа/бана удаляются из памяти. Компромисс: очередь теряется при перезапуске.
- **Баны** хранятся как `SHA-256` хеши Telegram ID, исходный ID в базу никогда не пишется.
- **Стейты пользователей** — в памяти (`DashMap`), не в таблице.
