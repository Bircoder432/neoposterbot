# PosterBot Constructor

Мультиарендный конструктор анонимных Telegram-предложек: один **мастер-бот** позволяет любому клиенту привязать собственного бота, настроить канал и управлять модерацией. Подписчики пишут боту анонимно, модераторы клиента одобряют или отклоняют контент кнопками — команды почти не нужны, всё дублируется инлайн-кнопками.


## Как это устроено

В проекте живут два типа ботов:

- **Мастер-бот** (управляется `MASTER_BOT_TOKEN`) — панель владельца сервиса и кабинет клиента: привязка ботов по токену, оплата PRO через Telegram Stars, промокоды, бан/разбан клиентов, статистика и рассылка.
- **Воркер-боты** (токены клиентов) — у каждого свой канал, свои модераторы, своя языковая локаль. Воркеры поднимаются автоматически при старте и по мере привязки новых ботов.

| Тариф | Ботов | Активных модераторов | Вотермарка | Цена |
|---|---|---|---|---|
| **Free** | 1 | 2 (остальные добавляются «замороженными») | есть | 0 |
| **PRO** | без лимита | без лимита | отключена | настраивается владельцем (срок и цена в разделе «⚙️ Настройки PRO», по умолчанию 30 дней за 100 ⭐) |

Срок и цену PRO владелец меняет в любой момент кнопками из меню; промокоды выдают бесплатный PRO на N дней или скидку на покупку (применяется автоматически при оплате).

## Возможности

### Мастер-бот (владелец сервиса)
- 👑 Панель управления с кнопками: клиенты, боты, статистика, рассылка, промокоды, настройки PRO, личный кабинет.
- 🚫 **Заблокированные** — отдельное меню забаненных клиентов: разбан в один тап без поиска по списку.
- 🎁 Промокоды: тип (бесплатный PRO / скидка %), срок, лимит активаций, вкл/выкл, удаление.
- ⚙️ Настройки PRO: срок подписки и цена в Stars (кнопки или ручной ввод).
- 🌐 Выбор языка интерфейса (🇷🇺/🇬🇧) — отдельно для владельца и для каждого клиента (`/lang` или кнопка).
- Команды: `/menu`, `/stats`, `/clients`, `/bots`, `/broadcast`, `/setplan <id> <free|pro>`, `/banclient <id>`, `/check @bot`, `/lang`.

### Мастер-бот (клиент)
- ➕ Привязка бота по токену от @BotFather с проверкой, «Мои боты» с отвязкой, проверка чужого бота по юзернейму.
- ⭐ Покупка PRO через Telegram Stars; 🎁 активация промокодов; 🌐 язык; 📚 ссылка на инструкцию.
- На Free — один активный бот (повторная привязка того же бота не считается), лимит снимается на PRO.

### Воркер-бот (владелец бота и модераторы)
- Кнопочные панели: предложения, жалобы, модераторы (приглашение ссылкой на 24 часа), ЧС юзернеймов, журнал действий, ответы на посты, язык, уведомления.
- 🚫 **Заблокированные** — единое меню банов: список активных банов с кнопкой разбана у каждого (отдельная команда ввода кода больше не нужна; `/pardon <BAN-ID>` остался для точечного разбана).
- 🔔 Уведомления о новых предложениях и жалобах приходят с кнопкой модерации и настраиваются вкл/выкл каждым пользователем.
- 🌐 Язык бота выбирается при первой настройке и меняется в меню (`/lang en|ru`).
- Замороженные модераторы (сверх лимита Free) не могут модерировать, но переключают язык; владелец размораживает их кнопкой после перехода на PRO.

## Стек

Rust 1.94 · teloxide 0.17 · PostgreSQL 16 · sqlx · Docker.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `MASTER_BOT_TOKEN` | Токен мастер-бота от @BotFather |
| `OWNER_ID` | Telegram ID владельца сервиса |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `WATERMARK_USERNAME` | Юзернейм для вотермарки Free-ботов (например `@superduperbot`) |
| `INSTRUCTION_URL` | Ссылка на кнопку «Инструкция» |
| `RUST_LOG` | Уровень логов (`posterbot_constructor=info,teloxide=info`) |

Шаблон — `.env.example`.

## Деплой

### Из исходников

```bash
cp .env.example .env   # заполнить
docker compose up -d --build
```

Поднимутся PostgreSQL (том `pgdata`) и приложение; миграции применяются автоматически при старте.

### Готовый образ из ghcr.io

```yaml
# compose.yml (фрагмент)
constructor_bot:
  image: ghcr.io/bircoder432/neoposterbot:latest
  restart: unless-stopped
  env_file: .env
  depends_on: [db]
```

```bash
docker compose pull
docker compose up -d
```

### Обновление на v2.0

Новых миграций в v2.0 нет — достаточно заменить образ/бинарник и перезапустить: новые настройки PRO и лимиты Free читаются на лету. История миграций — в каталоге `migrations/`.

## Особенности хранения данных

- **Предложения** живут только в оперативной памяти и не попадают в БД — после публикации/отказа/бана удаляются. Очередь теряется при перезапуске.
- **Баны** хранятся как `SHA-256` хеши Telegram ID, исходный ID в базу никогда не пишется.
- **Стейты пользователей** — в памяти (`DashMap`), не в таблице.
- **Языки** — у каждого воркер-бота свой (таблица `bots.lang`), у каждого клиента мастер-бота свой (`clients.lang`).

## Структура проекта

```
src/
├── bot/
│   ├── master/      # мастер-бот: меню, промокоды, PRO, язык, баны клиентов
│   ├── worker/      # воркер-боты: предложения, жалобы, баны, модераторы
│   ├── manager.rs   # запуск/остановка воркеров
│   └── media.rs     # публикация постов и вотермарка
├── db/              # sqlx-репозиторий и модели
├── locales.toml     # все тексты (ru/en)
└── config.rs        # переменные окружения
migrations/          # SQL-миграции (0001–0010)
```
